# 이자부부채(IBD) 산정 정책 — kr-valuation-data

판: v0.2 (2026-09-30, 엔진 `ibd-v2.2.1` 기준) · 대상: `valuation_get_data` 의 `ibd`

이 문서는 "무엇을 이자부부채로 보는가"의 기준이다. 엔진(`src/services/opendart/ibd-engine.ts`)과 독립 검증(주석 원문 대조)이 모두 이 문서를 따른다.

## 1. 정의와 측정

- **정의**: 평가기준일 현재 채권자에게 상환할 의무가 있는 이자부 조달 잔액. DCF 순차입금·EV 산정용.
  - 순차입금 = IBD − 현금및현금성자산 − 단기금융상품, EV = 보통주 시가총액 + 순차입금 + 비지배지분
- **측정**: K-IFRS 재무상태표 **장부금액**(상각후원가, FVTPL 지정분은 공정가치). 액면·상환금액이 아니다.
- **조정계정**: 사채할인발행차금·전환권조정·신주인수권조정·현재가치할인차금은 **그 본계정이 IBD에 포함될 때만** 차감한다. 사채상환할증금은 가산한다.
- **기준 재무제표**: 연결재무제표가 있으면 연결, 없으면 별도. 보고서는 평가기준일 당시 공시된 최신 정기보고서.
- **유동/비유동**: 재무상태표 본문의 유동부채·비유동부채 구역을 따른다.

## 2. 포함 — 범주

| 범주(`byCategory`) | 포함 항목 |
|---|---|
| `borrowings` 차입금 | 단기·장기·유동성장기 차입금(금융기관·특수관계자·주주·정책자금), 당좌차월(현금과 상계하지 않음), 본문에 표시된 PF 차입금, 재무상태표에 차입으로 표시된 유산스 |
| `bonds` 사채 | 일반사채·회사채(할인발행차금 차감, 상환할증금 가산), 기업어음, 전자단기사채 |
| `convertible` 전환사채 등 | 전환사채·신주인수권부사채·교환사채의 부채요소(전환권조정 차감, 상환할증금 가산), FVTPL 지정 복합금융상품 중 사채 |
| `borrowingsAndBonds` 차입금·사채(구분 불가) | 한 계정에 차입금과 사채가 함께 표시된 행(예: '차입금및사채', '사채및장기차입금'), 주석 총계로만 확인되는 차입금·사채 |
| `lease` 리스부채 | 리스부채(유동·비유동, IFRS 16), 금융리스부채 |
| `otherDebt` 기타 차입성 부채 | 유동화채무·ABL·자산유동화차입금, 판매후리스부채(1116 판매 요건 불충족), 상환청구권 있는 채권할인 차입 |

- `total` = 위 범주의 합. **리스는 기본 포함**(IFRS 16 이후 EBITDA·EV 와 짝). 리스 제외값 = `total − byCategory.lease`.

## 3. 제외 — 합계에 넣지 않음

| 항목 | 처리 |
|---|---|
| 상환전환우선주부채(RCPS)·상환우선주·전환우선주부채(CPS) | `debtLike` (유형 `rcps`/`cps`, 계정명 기준 추정) — 내가격이면 희석, 아니면 부채 가산을 사용자가 판단 |
| 전환권·신주인수권·교환권 파생상품부채 | `debtLike` (유형 `convDerivative`) |
| 신종자본증권·영구채·조건부자본증권(부채 분류분) | `debtLike` (유형 `hybrid`) |
| 파생상품부채(헤지·일반), 금융보증부채 | 제외 |
| 미지급이자, 미지급금·장기미지급금, 매입채무(유산스 포함 표시 시에도 매입채무면 제외) | 제외 |
| 임대보증금·예수보증금·예수금 | 제외(그 현재가치할인차금도 IBD 에서 차감하지 않음) |
| 순확정급여부채, 충당부채(하자·복구·소송), 계약부채·초과청구공사, 이연수익 | 제외 |
| 매각예정 처분자산집단 부채 | 제외 — `notes` 와 `meta.heldForSale` 로 표시 |
| PF 보증·자금보충 약정 등 부외 우발부채, 공급자금융약정 | 제외 |

## 4. 업종·연결 범위

- **산정 제외(`ibd = null`, `ibdExcluded` 에 사유)**: 은행(641)·금융지주 등(642)·보험(65)·증권(6611·6612)·여신전문 카드·할부·리스(64911~64913), 그리고 유동/비유동 구분이 없고 예수·보험계약·당기손익금융부채 계정이 있는 금융업 형태 재무상태표.
- **포함 + 참고**: 신기술금융·VC(6491·64919·649 계열 일부), 결제·PG(66199), 보험대리점(66202), SPAC — `금융 관련 업종` note.
- **비금융 지주(64992)**: 연결 IBD.
- **금융 자회사를 연결한 비금융 기업**(현대차·다우기술 등): 연결값 그대로 두고 note 로 알린다. 신호는 예수부채·보험계약부채·금융업채권 등 금융업 계정 합계가 자산총계의 5% 이상일 때. 이미 '금융 관련 업종' note 가 붙는 회사(업종 64~66, 64992 제외)에는 따로 붙이지 않는다. 모회사 별도 수치를 "금융부문 제외" 대안으로 쓰지 않는다.

## 5. 산정 무결성 원칙

- **중복 제거**: 포괄 행(구성 행의 합계 행)은 구역 소계 초과(1% 초과)·구성 행 부분합과 정확히 일치·구조 증거(계층형 연속 블록, 포괄형 이름 등)가 모두 있을 때만 뺀다. 금액이 우연히 같다는 이유만으로 빼지 않는다.
- **주석 보충**: 본문이 '금융부채'로 묶여 차입금이 보이지 않으면 같은 보고서의 XBRL 주석 금액으로 보충한다. 본문에 이미 있는 금액은 더하지 않고, 해당 구역 부채 소계를 넘는 주석 금액은 보충하지 않는다.
- **부호**: 차감계정만 음수. 차감계정이 아닌 음수 차입 행은 구역 소계가 뒷받침할 때만 부호를 보정하고, 아니면 경고한다.
- **완전성**: 차입이 빠졌을 가능성이 있으면 `completeness: "partial"` 과 사유를 붙인다(조용한 0·조용한 과소 금지).
- **데이터 품질**: 다음이면 재무 레코드 전체(IBD·현금·자본·손익)를 보류한다.
  - IBD 가 부채총계를 넘음(단위·태깅 오류 또는 이중 계상)
  - IBD 500조 초과
  - 직전 정상 보고서 대비 자본이 100배 이상 변하고 IBD(무차입이면 현금)도 같은 배율로 변함 — 직전 보고서가 이상치면 그 앞과 비교, 직전이 자본잠식이면 비교하지 않음
- **주석 XBRL 을 못 받은 경우**: 통신 오류·미확보는 항상 `partial`, XBRL 이 없거나 문맥이 없으면 묶인 금융부채가 부채의 30% 이상일 때만 `partial`(미만이면 참고).
- **순서 비의존**: DART 행 순서(ord)는 화면 표시 순서가 아니므로, 계층형 부모·자식 판정 외에는 순서에 의미를 두지 않는다.

## 6. 알려진 한계(다음 판에서 다룸)

- 리스부채가 '기타(금융)부채' 안에 섞여 본문에 따로 없으면 합계에 들어가지 않는다(주석에만 있는 리스).
- 부문 축 기반 "금융부문 제외 IBD" 는 제공하지 않는다.
- 분기 XBRL 이 회사 고유 확장 요소로만 차입금을 태깅하면 주석 보충이 되지 않는다(`completeness: "partial"` 로 표시).
